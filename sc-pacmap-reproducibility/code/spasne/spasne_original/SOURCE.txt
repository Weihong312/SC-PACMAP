Our code
--------
No project-authored integration code is stored in this directory. The adjacent
../spasne_adapter.py and ../spasne_wsl_bridge.py are the SC-PaCMAP project
integration. They provide validation, path handling, and Windows-to-WSL
execution without modifying the upstream SpaSNE implementation.

Build artifact
--------------
Run `make` in this directory on Linux or WSL. The resulting `spasne` executable
is generated locally and is not source code.
