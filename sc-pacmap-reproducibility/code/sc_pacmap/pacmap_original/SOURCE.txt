What is new and not claimed as original PaCMAP
----------------------------------------------
All new work is isolated in ../sc_pacmap.py:

1. Three-mode if/elif selector.
2. Input validation.
3. Mode 2 concatenation of features and separately standardized XYZ.
4. PCA-Geary spatial-continuity calculations.
5. Automatic k_spatial / k_attribute allocation.
6. Construction of the replacement nearest-neighbour pair matrix.
7. Verification functions comparing:
   - copied PaCMAP against installed pacmap==0.9.1;
   - SC disabled against copied ordinary PaCMAP.

SC-PaCMAP changes only pair_neighbors. After that matrix is constructed,
original generate_pair_no_neighbors() creates the mid-near and further pairs,
and original pacmap() performs initialization, all three loss phases, gradients,
and Adam optimization.
